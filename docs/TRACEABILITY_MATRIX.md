# Notebook Traceability Matrix

No behaviorally relevant notebook cell or logical cell group may remain unmapped at final completion.

## Status values

- `UNMAPPED`
- `MAPPED`
- `IMPLEMENTED`
- `PARITY VERIFIED`
- `EQUIVALENT WITH DOCUMENTED DIFFERENCE`
- `BLOCKED`
- `NOT APPLICABLE`

| Notebook section / cell reference | Stable description | Inputs | Outputs / side effects | Target module | Function / class | Test(s) | Streamlit page / component | Parity status | Known issue |
|---|---|---|---|---|---|---|---|---|---|
| Populate in Phase 1 | | | | | | | | UNMAPPED | |

## Completion checks

- [ ] Every executable or behaviorally relevant cell is represented.
- [ ] Every mapping identifies a module and callable or explains why not applicable.
- [ ] Every deterministic behavior has a test or a written justification.
- [ ] Every user-facing behavior maps to a UI destination.
- [ ] Every discrepancy links to `KNOWN_ISSUES.md`.
